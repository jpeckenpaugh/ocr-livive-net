Dataset Sources & Academic Citations

This project uses standard open benchmark datasets for digit and letter recognition. All training and inference is performed locally in WebAssembly with zero telemetry or server calls.

1. MNIST Database of Handwritten Digits

The MNIST database is a subset of a larger set available from NIST (National Institute of Standards and Technology). It was created by Yann LeCun, Corinna Cortes, and Christopher J.C. Burges to serve as an accessible pattern recognition benchmark.

Citation:
LeCun, Y., Cortes, C., & Burges, C. J. (2010). MNIST handwritten digit database. ATT Labs [Online]. Available: http://yann.lecun.com/exdb/mnist

2. EMNIST: Extended MNIST for Letters

The EMNIST dataset extends MNIST into handwritten letters, derived from the NIST Special Database 19. It shares the identical 28×28 pixel grid, integer intensity scaling, and normalization pipeline as MNIST.

Citation:
Cohen, G., Afshar, S., Tapson, J., & van Schaik, A. (2017). EMNIST: Extending MNIST to handwritten letters. 2017 International Joint Conference on Neural Networks (IJCNN), 2921-2926.
DOI: 10.1109/IJCNN.2017.7966217

3. Font Licensing (SIL Open Font License)

When synthesizing character bitmaps from typographic fonts, open-source fonts licensed under the SIL Open Font License (OFL) v1.1 are utilized. Under Section 1 and OFL FAQ §1.1, rasterizing font outlines into static bitmap images produces unencumbered pixel data suitable for training and evaluation.

The Pipeline: 28×28 Normalization

When drawing on the canvas, input follows the original NIST centering rules:

  1. Grayscale conversion: (299·R + 587·G + 114·B + 500) / 1000.
  2. Bounding-box extraction of non-black pixels, expanded to a square.
  3. Box-filter downsampling into a 20×20 bounding box with half-up rounding.
  4. Centroid of mass alignment: Translates the ink center to coordinates (14, 14) in the 28×28 output grid.

How to Run in Python (onnxruntime)

import onnxruntime as ort
import numpy as np

# Load model
session = ort.InferenceSession("mlp.onnx")

# Query shape: [1, 784] float32 pixels in range 0..255
dummy_input = np.zeros((1, 784), dtype=np.float32)
outputs = session.run(None, {"input_pixels": dummy_input})

probabilities = outputs[0]  # shape: [1, num_classes]
predicted_idx = np.argmax(probabilities)
print("Predicted class index:", predicted_idx)

Centroid Classifier Details

Intuition & Model Architecture

The centroid classifier computes the arithmetic mean image for each of the digit or letter classes. At inference time, it computes the Euclidean distance between the unknown image and each prototype image.

d_c = √( Σ (x_i - μ_{c,i})² )
prediction = argmin_c(d_c)

k-Nearest Neighbors (k=3) Details

Intuition

k-NN has zero training time: the model is literally the dataset. For an input image, it searches through all N training samples, identifies the 3 closest images under Euclidean distance, and awards the prediction to the majority vote.

D(x, y) = √( Σ (x_i - y_i)² )
prediction = majority_vote(top_k(D))

Multiclass Perceptron Details

Intuition & Math

A single linear layer mapping 784 inputs directly to class logits, followed by numerically stable Softmax normalization.

z_c = b_c + Σ w_{c,i} · (x_i / 255)
p_c = exp(z_c - max(z)) / Σ exp(z_j - max(z))
Loss = -log(p_{true})

Multi-Layer Perceptron (ReLU) Details

Network Architecture

784 input units → 64 hidden units with Rectified Linear Unit (ReLU) activation → Output units with Softmax. Trained via hand-written backpropagation with mini-batch SGD.

h = max(0, W_1 · x + b_1)
logits = W_2 · h + b_2
∂L/∂logits = p - y
∂L/∂W_1 = ((∂L/∂logits · W_2) ⊙ [h > 0]) ⊗ x
